Claude Code의 다양한 기능과 명령어를 실험하고 검증하기 위한 테스트 환경입니다.

## 테스트 기능 목록

### 1. 코드 생성 및 편집
- 새 파일 생성 테스트
- 기존 파일 수정 테스트
- 멀티 파일 동시 편집

### 2. 코드 분석
- 코드 구조 분석
- 패턴 검색 및 탐지
- 의존성 분석

### 3. 문서화
- README 자동 생성
- API 문서화
- 코드 주석 생성

### 4. 리팩토링
- 코드 개선 제안
- 성능 최적화
- 보안 취약점 검사

### 5. 테스트 코드
- 유닛 테스트 생성
- 통합 테스트 생성
- 테스트 커버리지 분석

### 6. Git 워크플로우
- 커밋 메시지 생성
- PR 생성 및 관리
- 브랜치 전략

### 7. 프로젝트 관리
- 태스크 관리
- 복잡한 작업 분해
- 작업 진행 상황 추적

## 사용 방법

### 기본 명령어

```bash
# 코드 분석
/analyze [target]

# 코드 개선
/improve [target]

# 문서 생성
/document [target]

# 테스트 실행
/test [type]

# Git 작업
/git [operation]
```

### 플래그 옵션

```bash
# 계획 먼저 보기
--plan

# 깊은 분석
--think

# 토큰 압축 모드
--uc

# 안전 모드
--safe-mode

# 상세 출력
--verbose
```
